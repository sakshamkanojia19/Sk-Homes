🏠 SK Homes – Real Estate Booking & Exploration Platform
Welcome to SK Homes, a modern real estate web application where users can effortlessly explore, filter, and book properties for visits with a smooth and engaging experience. This full-stack project integrates powerful tools like MongoDB, Node.js, React.js, Prisma ORM, and Leaflet Maps to deliver a dynamic property discovery platform.

🔗 Live Demo: https://sk-homes-phi.vercel.app/

🌟 Features
🔍 Advanced Property Search & Filtering
Search properties by name, location (place/city), number of bedrooms, room size, parking availability, and other key specifications.

📍 Interactive Leaflet Map Integration
Explore properties using a visually intuitive and interactive map powered by Leaflet.js.

❤️ Favorite Properties
Mark properties as favorites and manage your wishlist seamlessly.

📅 Schedule a Visit
Book a visit for any property on your preferred date. We ensure your site visit is smooth and hassle-free.

🔐 OAuth Authentication
Secure login/signup with OAuth (Google Sign-In) for quick and safe access.

💅 Beautiful UI/UX
Stunning responsive interface using Tailwind CSS, Material UI, and custom UI components for a polished user experience.

📌 How to Use
Visit the Website: SK Homes Live

Explore Listings: Use the search bar or filters to find properties.

Map View: View listings on the interactive Leaflet map.

Authentication: Log in via Google to unlock full features.

Favorites: Click the ❤️ icon to favorite listings.

Book a Visit: Select a date and submit a request to visit the property.
